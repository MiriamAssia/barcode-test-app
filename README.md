# אפליקציית טסט - סריקת ברקוד

אפליקציה מינימלית שבודקת שסריקת ברקוד/QR עובדת על הטאבלט, לפני שממשיכים לבנות את אפליקציית המלאי המלאה.

## איך בונים את ה-APK (בלי להתקין שום דבר על המחשב שלך)

1. היכנסי ל-https://github.com ופתחי חשבון חינמי (אם אין לך עדיין).
2. לחצי על "New repository", תני לו שם (למשל barcode-test-app), השאירי אותו Public או Private (לא משנה), ולחצי Create repository.
3. בעמוד של הריפוזיטורי החדש לחצי על "uploading an existing file", וגררי לתוכו את **כל** התוכן של התיקייה הזו (כולל תיקיית `.github` הנסתרת - חשוב לא לדלג עליה).
4. לחצי Commit changes.
5. עברי ללשונית "Actions" בראש העמוד. את תראי workflow בשם "Build APK" רץ אוטומטית (אם הוא לא התחיל לבד, לחצי עליו ואז על "Run workflow").
6. חכי כ-3-5 דקות עד שהריצה תסתיים (עיגול ירוק ✓).
7. לחצי על הריצה שהסתיימה, גללי למטה לאזור "Artifacts", ולחצי על הקובץ בשם barcode-test-app להורדה (הוא יגיע כ-zip, בפנים יש את app-debug.apk).
8. חברי את הטאבלט למחשב בכבל USB (או העבירי את הקובץ בכרטיס זיכרון), והעתיקי את app-debug.apk לטאבלט.
9. בטאבלט, פתחי את מנהל הקבצים, לחצי על app-debug.apk כדי להתקין. אם מופיעה הודעה שחוסמת התקנה ממקור לא ידוע - יש לאשר בהגדרות ("התקן אפליקציות לא ידועות") עבור מנהל הקבצים.
10. פתחי את האפליקציה, תני הרשאת מצלמה, ולחצי "סרוק ברקוד".

בכל פעם שתרצי גרסה מעודכנת בעתיד - מספיק להעלות קבצים מעודכנים לריפוזיטורי (או לבקש ממני לעדכן אותם), וה-Actions תבנה APK חדש אוטומטית.
